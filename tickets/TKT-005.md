## Description

"Bikin proposal untuk membuat survei": a proposal step before a survey exists.
Draft a survey proposal (title, purpose, target, questions outline). Optional
verification step: send verification to an email address; the proposal moves
forward only when verification is approved. After approval, continue to the
"build questionnaire" step (wizard-style handoff).

## Acceptance criteria

- [ ] Proposal model (draft → pending verification → verified → approved)
- [ ] Optional email verification step (configurable per proposal)
- [ ] Approve action that unlocks the questionnaire builder step
- [ ] UI: proposal list/form + step handoff into questionnaire creation
- [ ] Integration with survey/questionnaire creation (align with org scoping TKT-014)
- [ ] Unit + integration tests green

## Notes

Depends on TKT-014 (org scoping) if proposals create surveys inside an
organization. Email delivery reuses the mailer introduced by TKT-013.
