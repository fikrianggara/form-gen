## Description

Give every action button in the app a recognizable icon (view, add, edit, delete,
sign out, sign in, export, report, reset password, test, mailblast, reorder, info,
warning, drag handle) via one shared, dependency-free icon set, so the UI reads
consistently instead of mixing plain-text buttons and unicode glyphs.

## Acceptance criteria

- [x] New shared icon module `src/components/icons.tsx` exports stroke-based SVG icons (view, add, edit, delete, logout, login, duplicate, report, list, download, back, key, bolt, info, warning, mail, chevrons, grip, more), sized via a `size` prop, inheriting text color — no new npm dependency.
- [x] Dashboard questionnaire list: New (+), View (eye), Responses (list), Report (chart), Edit (pencil), Duplicate (copy) all render icons (verified visually in browser on port 3118).
- [x] Sign out in the dashboard layout and Sign in on the login page render logout/login icons.
- [x] Responses and report page headers: Export API/Excel (download), Report (chart), Back to editor / Responses (arrow-left) render icons.
- [x] Admin panels: question masters (create/edit/delete/info), option sets (create/test/edit/delete), users (create/edit/reset password) render icons.
- [x] Questionnaire editor: Add question / Add block (+), move up/down (chevrons), drag grip, question & block info (info), low-confidence warning, Add/Edit rule (pencil), Remove/Delete (trash), rule-set clause add/remove — all render icons.
- [x] Public form renderer + response edit form: Add row (+), Remove row (trash), question description info icons render.
