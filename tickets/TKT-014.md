## Description

"Fitur scoping organization. Tiap organisasi bisa tambah survei, tiap survei bisa
punya multiple kuesioner. Operator hanya bisa akses survei n kuesioner di
organisasi yang sama. Master pertanyaan yang sama dengan user organization,
kecuali dipublish publik": multi-tenancy — Organization → Survey → multiple
Questionnaires per survey. Operators only access surveys/questionnaires inside
their own organization. Question masters are scoped to the user's organization
unless published publicly.

## Acceptance criteria

- [ ] Organization model + membership (users belong to an org)
- [ ] Survey model; Questionnaire belongs to a survey (nullable = legacy flat)
- [ ] Org-scoped access control for operators (surveys, questionnaires)
- [ ] Master questions org-scoped unless isPublic
- [ ] Admin can manage orgs and memberships
- [ ] Data migration path for existing flat questionnaires
- [ ] Unit + integration tests green
