## Description

"Fitur scoping organization. Tiap organisasi bisa tambah survei, tiap survei bisa
punya multiple kuesioner. Operator hanya bisa akses survei n kuesioner di
organisasi yang sama. Master pertanyaan yang sama dengan user organization,
kecuali dipublish publik": multi-tenancy — Organization → Survey → multiple
Questionnaires per survey. Operators only access surveys/questionnaires inside
their own organization. Question masters are scoped to the user's organization
unless published publicly.

## Acceptance criteria

- [x] Organization model + membership — `Organization` (name, unique slug,
      description) + `User.organizationId` (nullable; SetNull on org delete);
      `assignUserOrganization` / `listOrganizationUsers`; session payload now
      carries `organizationId` (legacy tokens read as null).
- [x] Survey model; Questionnaire belongs to a survey (nullable = legacy flat)
      — `Survey` (name, organizationId, Cascade on org delete) +
      `Questionnaire.surveyId` (nullable, SetNull on survey delete);
      `createSurvey` / `listSurveys` / `assignQuestionnaireToSurvey`.
- [x] Org-scoped access control for operators (surveys, questionnaires) —
      `assertCanManageQuestionnaire` allows creator, legacy-unowned, and
      same-org survey questionnaires; `assertCanAccessSurvey` gates surveys to
      the operator's org; ADMIN bypasses both.
- [x] Master questions org-scoped unless isPublic — `QuestionMaster.organizationId`
      (nullable = shared/legacy) + `isPublic`; `listQuestionMasters` scopes to
      public + legacy + own-org (admins see all via `{ all: true }`); masters
      are created into the creator's org; Public/Private toggle in the admin
      masters panel.
- [x] Admin can manage orgs and memberships — new `/admin/orgs` page
      (create/rename org, per-org surveys + questionnaire counts, member
      assign/unassign) + org-scoped questionnaire→survey selector in the
      editor Settings card.
- [x] Data migration path for existing flat questionnaires — all new columns
      are nullable with no backfill; legacy rows (survey null, org null, master
      org null) remain visible/workable, so existing data keeps functioning.
- [x] Unit + integration tests green — 22 new org-service integration tests
      (orgs, membership, surveys, assignment, cross-org denial, master
      visibility) + session legacy-token test; full suite 389/389 green;
      tsc + lint clean.
