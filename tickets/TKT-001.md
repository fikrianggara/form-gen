## Description

Re-scoped by owner (2026-08-14): respondents do NOT need accounts. The system
generates a unique link per sample email and mailblasts the link to the emails
listed as the sample (if the questionnaire has one). Clicking the link opens
the public form. Generating links creates NO questionnaire/response data;
a blank Response row is created only when the link is clicked and the
respondent saves it as a draft (or completes).

Implementation plan: `.hermes/plans/2026-08-14_160000-unique-link-distribution.md`.

## Acceptance criteria

- [ ] Questionnaire holds an optional sampleEmails list
- [ ] Generate-links action creates one Invitation row per email (unique token); NO Response rows yet
- [ ] Mailblast sends each sample email the unique link (SMTP when configured, console fallback otherwise)
- [ ] Public link validates, marks the invitation clicked, and renders the form
- [ ] First save (draft/complete) lazily creates the Response (respondentToken=token, respondentLabel=email)
- [ ] Anonymous flow (no invite) unchanged
- [ ] Unit + integration tests green
