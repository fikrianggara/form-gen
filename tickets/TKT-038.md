## Description

Retention and cleanup policy for the append-only `ApiRequestLog` table
(analysis v03 §10.7): define how long request metadata is kept and purge
older rows so the table cannot grow without bound.

## Acceptance criteria

- [x] Retention window configurable via env (e.g. `API_LOG_RETENTION_DAYS`, default 90)
- [x] Cleanup routine (script or cron-invokable service) deletes ApiRequestLog rows older than the window in batches; safe to run repeatedly
- [x] Documentation of the policy in the developer guide or ops notes
- [x] Unit test for the purge query (bounded delete, respects window, idempotent)
