## Description

"Multi rule untuk tiap butir pertanyaan, depend ke pertanyaan lain, kondisional
OR dan AND, perlu validation engine": replace the single visibility rule with
multiple rule SETS per question. A question can have several independent rule
sets combined with OR; within a set, conditions combine with AND (or mixed).
A validation engine validates rule references (question exists, type-valid
operators, no cycles, no self-dependency) at save time.

## Acceptance criteria

- [ ] Rule schema: multiple rule sets per question, OR between sets, AND/OR within
- [ ] Evaluation engine handles nested combinators (unit-tested)
- [ ] Validation engine: bad question refs, invalid operators, cycles, self-refs rejected
- [ ] Builder UI: rule editor supports adding/removing rule sets
- [ ] Public form evaluates correctly (regression suite for existing single-rule forms)
- [ ] Unit + integration tests green
