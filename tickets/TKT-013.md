## Description

"Bisa mailblast email respondend": bulk email to respondent emails — e.g. invite
to fill the questionnaire or notify about status. Requires collecting respondent
emails (via respondent accounts or an email question).

## Acceptance criteria

- [x] Mailer integration with template — `mail.service.ts` (console fallback +
      SMTP-ready transport), invitation + reminder templates; `sendMail` now
      returns the failure reason (`{ delivered, error? }`).
- [x] Respondent email list source — the unique-link flow already collects
      per-recipient emails (Invitation rows; TKT-001 + TKT-012 sampling frame
      EMAIL contacts); reminders target every invitation that was sent but not
      yet clicked.
- [x] Send + status tracking (sent/failed) UI for operators — Invitation gains
      `deliveryError` (persisted failure reason, cleared on success); the
      editor's link list shows Sent / Failed / Revoked badges; a
      "Remind non-respondents" button re-mails sent-but-unclicked invitations
      and reports reminded/failed counts.
- [x] Unit + integration tests green — 6 new integration tests
      (`tests/integration/mailblast.service.test.ts`: failure recording,
      failure→success cycle, sent-but-not-clicked targeting, revoked skip,
      failure counting, reminder subject); full suite 362/362 green.
