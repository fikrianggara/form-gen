## Description

Every questionnaire can upload its sampling frame. Clarified by the owner
(2026-08-15, finding F-015): "sample" = the **sampling frame** of a survey —
the known list of target respondents (person or organization) for a targeted
survey. Uploaded via an Excel file, with a fixed column format. This
subsequently powers invitation distribution: each row becomes a sample entry
that can receive a unique link (TKT-001 flow).

## Acceptance criteria

- [x] Questionnaire can store a sampling frame — new `SamplingFrameEntry`
      model (organizationName, contact, contactType EMAIL|PHONE, rowIndex),
      cascade-deleted with the questionnaire; upload REPLACES the frame while
      the free-text `sampleEmails` list remains for legacy use.
- [x] Upload accepts an Excel (.xlsx) file with columns `organization_name` +
      `contact`; header matching is case/whitespace tolerant; contact may be an
      email or a phone number (>= 7 digits, optional +/spaces/dashes).
- [x] Upload validates the format: missing required columns → structural error;
      empty org/contact rows and implausible contacts → clear per-row errors;
      valid rows are imported and invalid rows reported (never a silent
      partial). Excel parse in `excel.service.ts` (`parseSamplingFrameWorkbook`).
- [x] Uploaded entries are visible/editable in the questionnaire settings —
      `SamplingFrameCard` in the editor: upload control, per-row error list,
      entry table with EMAIL/PHONE badges and per-row remove.
- [x] Sampling-frame entries feed the unique-link distribution flow —
      `sendInvitations` merges legacy `sampleEmails` + frame EMAIL contacts
      (deduped); PHONE contacts are not emailed (flagged for other channels).
- [x] Unit + integration tests green — 8 parse unit tests + 6 service
      integration tests (list/replace/delete/emails/send-invitations); full
      suite 356/356 green.

## Notes

Clarification resolved 2026-08-15 (F-015): the sample is the sampling frame
for targeted surveys where the respondent is known (person or organization).
Format: organization_name + contact (phone or email). Builds on the TKT-001
invitation/mail services. Coordinates with TKT-013 (mailblast) for delivery.
