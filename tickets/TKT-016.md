## Description

Disabled form fields in the question-master and option-set admin panels looked
identical to enabled fields — no visual cue that they were locked. Add a
visible disabled state (gray background, dimmed text, not-allowed cursor).

- [x] Applies to master form (type-dependent fields) and option set form (source-dependent fields)
- [x] No behavior change — styling only
- [x] Gates green
