## Description

"Ketika generate form dari AI, flag pertanyaan yang ngga ada di db. User bisa
menambah pertanyaannya sendiri, munculin modal untuk tambah pertanyaan yang sama
di master questionnaire, nanti pertanyaan divalidasi oleh admin kalau mau
dipublish, secara default hanya muncul questionnaire yang dibuat oleh admin dan
yang dibuat sendiri": AI generation must flag questions that do NOT exist in the
master bank (novel AI questions). The user can keep their own questions, and a
modal offers "add this question to the question master". Newly suggested masters
enter a PENDING state, validated by an admin before publish. Master visibility:
by default only admin-created masters and the user's own masters are visible.

## Acceptance criteria

- [ ] AI generation distinguishes bank matches vs novel questions (flagged)
- [ ] Modal per novel question: add to master questionnaire (pending state)
- [ ] Master PENDING → PUBLISHED admin validation workflow
- [ ] Master visibility filter: admin + own by default, published public opt-in
- [ ] Builder + AI generation surfaces respect the visibility filter
- [ ] Unit + integration tests green
