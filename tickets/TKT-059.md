## Description

The public homepage (`src/app/page.tsx` + `Hero` component) shows no signed-in
state. When logged in, show the username and a Dashboard link in the home
header; the Dashboard link appears only when authenticated.

Owner request (2026-08-21): "kalo udah sign in, bakal ada username di
homepage. dashboard di navbar home juga cuma dimunculin kalo udah login."

## Acceptance criteria

- [x] `Hero` (or a small header component) reads the session via
      `getSession()`; authenticated → renders username (and role badge) +
      "Dashboard" link; anonymous → "Sign in" link as today.
- [x] No server error or flash of logged-out state for authenticated users
      (rendered server-side; force-dynamic where needed).
- [x] Landing page visual style (TKT-048/050) preserved.
- [x] Test: session present → Dashboard link renders; absent → not rendered.
