## Description

Dashboard UI for administrators to manage API keys: list all keys with
metadata, issue keys directly (bypassing the portal), revoke, and view usage
stats from ApiRequestLog (analysis v03 §6.7, §8).

## Acceptance criteria

- [ ] Admin-only page `/admin/api-keys` (ADMIN role enforced server-side)
- [ ] Key list: prefix, name, scopes, status, expiresAt, lastUsedAt, createdBy, createdAt — never the secret; status badges (ACTIVE/REVOKED/EXPIRED)
- [ ] Issue key form: name, scopes (multi-select of the 5 read scopes), optional expiry; on create shows full secret once with copy button + warning
- [ ] Revoke action with inline confirm (per UX convention: explicit labeled actions + confirm for consequential ops); revoke flips status to REVOKED
- [ ] Usage view: per-key request counts, recent requests (method/path/status/duration) from ApiRequestLog
- [ ] Error/loading states consistent with existing admin panels; tests for RBAC + issue + revoke flows
