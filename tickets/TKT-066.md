## Description

One-click copy for API keys: a copy button on the key prefix (and on the
one-time secret reveal) in the API keys panel
(`src/components/admin/ApiKeysPanel.tsx`, `src/components/portal/ApiAccessRequestForm.tsx`).

Owner request (2026-08-21): "ada fitur copy key di api key."

## Acceptance criteria

- [ ] Copy button next to the key prefix copies `keyPrefix` to clipboard;
      button shows a transient "Copied" state.
- [ ] When a newly issued/approved secret is displayed once, a copy button
      copies the full secret (that is the only moment the plaintext exists).
- [ ] Uses `navigator.clipboard` with a fallback for insecure contexts; no
      secret is ever stored client-side after the reveal is dismissed.
- [ ] Reuses the labeled-action + toast patterns (Fikri UX preference:
      explicit buttons, toast feedback).
- [ ] Component test for the copy interaction (mock clipboard API).

## Notes

- Small, isolated; can be picked up any time. The secret-reveal copy is the
  sensitive one — make sure the secret value isn't left in DOM state after
  the modal closes.
