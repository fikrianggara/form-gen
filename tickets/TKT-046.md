## Description

Owner request (2026-08-19): add Swagger UI to the OpenAPI spec and expose it
as an API. The static spec exists (docs/openapi.yaml, TKT-037); this ticket
serves the spec over HTTP and renders interactive Swagger UI docs.

## Acceptance criteria

- [x] `GET /api/v1/openapi.yaml` (or `/api/docs/openapi.yaml`) serves the spec content with `Content-Type: text/yaml` — no auth required (documentation)
- [x] `GET /api/docs` (or `/docs`) renders Swagger UI pointing at the served spec; page loads without JS console errors
- [x] Swagger UI shows all 8 v1 endpoints with their scopes and the Bearer security scheme from the spec
- [x] Try-it-out works against a locally running server (authenticate with a test key)
- [x] Developer guide references the live UI URL
- [x] `npx tsc --noEmit` passes; lint + build green
