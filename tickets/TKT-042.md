## Description

The org feature has no survey page: a survey shows "0 questionnaires" but
there is no way to connect existing questionnaires to it from the survey
side. Add a dedicated survey page (view details, connect/disconnect existing
questionnaires) and delete-survey in both the org page and the survey page
(analysis v05 §1, §2, §3.4).

## Acceptance criteria

- [ ] Survey page route (e.g. `/admin/orgs/[orgId]/surveys/[surveyId]` or `/admin/surveys/[id]` — follow existing admin routing conventions): name, description, org, connected questionnaires list
- [ ] Connect questionnaires: picker/multi-select of EXISTING questionnaires (own-org + global for ADMIN; own-org only for OPERATOR); save persists join rows via the M2M service (TKT-041)
- [ ] Disconnect questionnaires: remove link only — questionnaire itself is NOT deleted; inline confirm for disconnect
- [ ] Delete survey on the survey page: inline confirm; deletes survey + join rows, KEEPS questionnaires; org gate ADMIN any / OPERATOR own org
- [ ] Delete survey in org page (OrgsPanel survey row): same confirm + semantics; opens/links to the survey page
- [ ] After delete/disconnect, counts and lists refresh (revalidatePath); errors shown consistently with other admin panels
- [ ] Tests: connect/disconnect, delete keeps questionnaires, RBAC (OPERATOR cannot touch foreign-org survey)
