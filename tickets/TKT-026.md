## Description

No CI pipeline exists; the gate chain (tsc → vitest → lint → build) is local
only. With parallel agents merging, schema/client drift and merge regressions
are caught only by whoever runs the local chain. From finding F-013.

## Acceptance criteria

- [ ] GitHub Actions workflow (or equivalent) runs the full gate chain on PR
      and on push to main
- [ ] Integration suite runs against a real Postgres service in CI (migrate +
      test)
- [ ] Gate failures block the PR / are visible on main
- [ ] Optional: cache npm deps to keep runs fast
