## Description

The table wrapper in the users panel (`src/components/admin/UsersPanel.tsx`)
and the responses list
(`src/app/dashboard/questionnaires/[id]/responses/page.tsx`) uses
`overflow-hidden rounded-xl` — the clip is needed to round the table's square
corners, but it ALSO clips absolutely-positioned descendant popup menus at the
box boundary. The kebab action menu (TKT-028/017/024) opens below the trigger
and is truncated at the table edge — the last row's menu is partially or fully
invisible. Reported by the owner: "the popup z-index is below the table, the
bottom item is not overflowing the table, it's truncated, I can't see the
action list." Root cause is ancestor `overflow-hidden`, NOT z-index (z-20 on
the menu is correct; no ancestor z-index can defeat a clip).

## Acceptance criteria

- [ ] Users table kebab menu is not clipped by the table wrapper; every menu
      item is fully visible on any row (including the last)
- [ ] Responses table action menu is not clipped either (same latent bug)
- [ ] Table corners stay rounded after removing the wrapper clip
- [ ] No layout regression: table still renders full-width, header styling
      unchanged
- [ ] Verified in a browser (menu opens over the page, not inside the table
      box); gate chain green

## Notes

Discovered by owner while reviewing TKT-028 (kebab menu) — "bottom item is
truncated". Fix approach: swap `overflow-hidden` → `overflow-visible` on both
wrappers and put the corner radius on the header cells
(`first:rounded-tl-xl last:rounded-tr-xl`) so the thead still hugs the border.
Same latent bug confirmed on the responses page (line 78) — fix both in one
run.
