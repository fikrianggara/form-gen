## Description

Analysis v06 R3 (owner decision 2026-08-17): the test suite is service-level
only — no component tests for interactive panels. Three concrete regression
classes were found by users, each a repeatable trap:

- A1: server action persists but the UI doesn't reflect it without reload
- A2: React event object (`e.currentTarget`) touched after an async gap → crash
- A3: popup/menu clipped by an `overflow-hidden` table wrapper

Add Testing Library component tests that exercise these panels at the DOM
level and wire them into the gate chain.

## Acceptance criteria

- [ ] Testing Library (@testing-library/react + jsdom environment) configured for vitest; a component test file runs in the normal `npx vitest run` gate
- [ ] Editor panel test: "add question" and "required toggle" reflect immediately without reload (regression for TKT-015, class A1)
- [ ] User-create form test: form resets after submit without `currentTarget` crash (regression for TKT-027, class A2)
- [ ] Table-wrapper test: kebab action menu fully visible (not clipped) when open inside a table wrapper (regression for TKT-030, class A3)
- [ ] All three tests pass in CI-equivalent local run (`npx vitest run` with jsdom config)
