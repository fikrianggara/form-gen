## Description

"Di option set, untuk response api yang lebih kompleks, bisa nentuin key apa yang
diambil dari response, bisa nested key": for complex external API responses,
let the option-set config pick which keys to extract — including nested keys
(not just the current itemsPath pointer).

- [ ] Admin UI: key fields with dot-path preview
