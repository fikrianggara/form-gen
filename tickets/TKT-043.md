## Description

Questionnaire pages do not show which surveys use a questionnaire. Add
survey tags/badges on the questionnaire list and detail, and make the
editor's survey selector a multi-select (one questionnaire can belong to
multiple surveys) (analysis v05 §2.2, §3.5).

## Acceptance criteria

- [x] Dashboard questionnaire list shows survey tag(s) per questionnaire (indigo badge with survey name + org; dashed "no survey" empty state)
- [x] Questionnaire edit page: survey selector is now multi-select chips (toggle connect/disconnect per survey), replacing the single-select dropdown; each toggle persists immediately via `connectQuestionnaireToSurveysAction` (replace-set)
- [x] Selector honors org rules: ADMIN sees all surveys; OPERATOR sees own-org surveys only (edit page fetches `listSurveys(orgId?)` scoped by session); changes persist via the M2M service (TKT-041)
- [x] `listQuestionnaires` includes the `surveys` relation with survey name + org name — single query, no N+1
- [x] Tests: tags render (list returns surveys + org), multi-select persistence (replace-set connect/disconnect covered), RBAC on visible surveys (listSurveys org scoping covered by TKT-014); full suite 474/474 green; tsc + lint clean
