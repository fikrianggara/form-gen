## Description

Questionnaire pages do not show which surveys use a questionnaire. Add
survey tags/badges on the questionnaire list and detail, and make the
editor's survey selector a multi-select (one questionnaire can belong to
multiple surveys) (analysis v05 §2.2, §3.5).

## Acceptance criteria

- [ ] Dashboard questionnaire list shows survey tag(s) per questionnaire (badge with survey name + org); empty state when unassigned
- [ ] Questionnaire edit page: survey selector becomes multi-select chips (connect/disconnect per survey), replacing the single-select dropdown
- [ ] Selector honors org rules: ADMIN sees all surveys; OPERATOR sees own-org surveys only; changing selection persists via the M2M service (TKT-041)
- [ ] `listQuestionnaires` includes `surveys` relation for tags; no N+1 (single query or Prisma include)
- [ ] Tests: tags render, multi-select persists, RBAC on visible surveys
