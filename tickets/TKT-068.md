## Description

After login the dashboard (`src/app/dashboard/page.tsx`) shows statistics:
counts of proposals, surveys, questionnaires, and responses. Also add an
explicit "Survei" tag on questionnaire cards — the survey chips already
render (`dashboard/page.tsx:66-84`); verify and label them so the owner sees
the tag they asked for.

Owner request (2026-08-21): "dashboard ketika login tampilin statistik jumlah
proposal, survei + yang ada di halaman kuesioner sekarang. ada tag 'survei' di
kuesionernya."

## Acceptance criteria

- [ ] Stat cards at the top of `/dashboard`: Proposals, Surveys,
      Questionnaires, Responses — counts are org/role-aware (ADMIN sees all;
      OPERATOR/DEV see their org's; scope decision noted in the ticket).
- [ ] Cards link to the relevant list pages (TKT-058 sidebar targets).
- [ ] Questionnaire cards show a labeled "Survei" tag (chip with the label +
      survey name(s)); if the existing unlabeled chips already satisfy the
      request, document that and only add the label.
- [ ] Counts reflect current DB state (server-rendered, force-dynamic); no
      caching staleness.
- [ ] Test: counts render with seeded data; role-scoped counts correct.
