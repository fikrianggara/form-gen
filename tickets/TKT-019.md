## Description

Invitation emails currently embed a RELATIVE link
(`/f/<slug>?invite=<token>` — `src/services/invitation.service.ts`,
`src/services/response-admin.service.ts`). Once real mail delivery lands
(TKT-020/013), recipients click a relative path that resolves against their
mail client, not the app. Add an absolute base URL configuration and build
links from it. From finding F-002.

## Acceptance criteria

- [ ] New env config for the app's public base URL (e.g. `APP_URL` /
      `NEXT_PUBLIC_APP_URL`), documented in `.env.example`
- [ ] `sendInvitations` and `mailblastRespondent` build
      `<base>/f/<slug>?invite=<token>` absolute links
- [ ] Missing/invalid base URL handled gracefully (config error surfaced, not
      silently broken links)
- [ ] Tests cover the link builder with and without base URL
