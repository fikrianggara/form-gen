## Description

A `/dashboard/profile` page where a signed-in user can: view/edit their name,
change their password (current password required), see their role and
organization, and request to join an organization (the join-request flow from
TKT-055). There is no profile page today; password changes exist only as an
admin action (`resetPassword` in `src/services/user.service.ts:123`).

Owner request (2026-08-21): "halaman profil, edit password, role kalo bisa,
organisasi."

## Acceptance criteria

- [ ] Profile page reachable from the app shell (top-bar menu / sidebar).
- [ ] Change password: requires current password + new password (min 8,
      `validatePassword`); verifies current via bcrypt; updates hash and
      keeps the session valid; other sessions unaffected or invalidated —
      decision noted in the ticket (prefer: keep own session, per TKT-029
      only isActive gates sessions).
- [ ] Name editing persists via `updateUser` (self-only).
- [ ] Role is displayed read-only for global roles; org-scoped role (after
      TKT-055/056) shown from membership.
- [ ] Organization section: shows current org; "Join organization" opens a
      search/select of organizations and submits a join request (TKT-055);
      "Leave organization" for members who are not the last org admin.
- [ ] Integration test: self password change, wrong-current-password rejected,
      name update, join request created.

## Notes

- Depends on TKT-055 for the join-request half; the profile shell, password
  change, and name edit can land first.
- Do not let a user change their own global role — "role kalo bisa" means
  display + org-scoped role via org admin (TKT-056).
