## Description

`buildInvitationMail` (`src/services/mail.service.ts`) interpolates
`questionnaireTitle` and `link` into the HTML body verbatim. A questionnaire
title containing markup injects into the email. From finding F-010.

## Acceptance criteria

- [x] `buildInvitationMail` HTML-escapes all interpolated values
      (new `escapeHtml()` in src/services/mail.service.ts; applied to
      `questionnaireTitle` and `link` in the HTML body — the href attribute
      and anchor text both use the escaped value; subject stays plain text)
- [x] A title with `<`, `>`, `&`, `"` renders as literal text in the email
      (unit test asserts `<script>alert("x")</script> & Co's Survey` renders as
      `&lt;script&gt;…` — no `<script>` tag survives in the body; `escapeHtml`
      covers all five metacharacters)
- [x] Existing mail tests updated; unit tests cover the escaping
      (tests/unit/mail.service.test.ts: existing build/send tests kept, new
      escaping test + escapeHtml metacharacter test)
