## Description

Owner reported: "bug ketika login dengan role sebagai dev." Suspected root
cause: after login as DEV, the dashboard navbar shows no Admin link
(`src/app/dashboard/layout.tsx:42` renders it only for `session.role ===
"ADMIN"`), yet `AdminLayout` admits DEV
(`src/app/admin/layout.tsx:11` allows ADMIN or DEV) — so a DEV with
`ISSUE_API_KEYS` has no visible way to reach the API keys UI, and admin
pages may render links DEV cannot act on. Needs reproduction and a precise
fix.

## Acceptance criteria

- [ ] REPRODUCE: log in as DEV (seed or create one), document the actual
      failure (wrong landing page? missing links? forbidden page error?) with
      evidence in the ticket notes before fixing.
- [ ] DEV lands on `/dashboard` after login exactly like OPERATOR/ADMIN.
- [ ] DEV can reach the API keys UI they have permission for (ISSUE_API_KEYS)
      — via the new sidebar (TKT-058) or an explicit DEV-visible link; the
      Admin-only links (Users, approve requests, manage master data) are
      hidden and blocked.
- [ ] DEV hitting an admin-only URL gets a proper forbidden/redirect, not a
      broken page or silent pass.
- [ ] Regression test: role-based nav renders + URL gate test for DEV.
