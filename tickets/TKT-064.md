## Description

The requested capability — "questions shown conditionally by rule, e.g. only
if question X = Y" — is ALREADY IMPLEMENTED: per-question `visibilityRule`
(TKT-006 multi-rule visibility engine), block-level `entryRule` (TKT-007),
and the `RuleSetsEditor` in the questionnaire editor. This ticket VERIFIES
the feature end-to-end in the respondent UI and fixes any gaps found, rather
than re-implementing it.

Owner request (2026-08-21): "pertanyaan bisa ditampilkan opsional berdasarkan
rule, misal hanya ditampilkan kalau pertanyaan x nilainya y."

## Acceptance criteria

- [ ] Author a questionnaire with a rule ("show Q2 only when Q1 = X") via
      RuleSetsEditor and confirm the rule is persisted in
      `QuestionnaireQuestion.visibilityRule`.
- [ ] Respondent flow (`src/components/forms/FormRenderer.tsx` + `/f/[slug]`)
      hides/shows the question correctly on change, including multi-rule
      OR/AND sets and block entry rules.
- [ ] Edge cases checked: rule referencing a question that was removed,
      empty/optional prior answer, repeatable parents, JSON response values.
- [ ] Any gap found gets fixed IN this ticket with a test; if everything
      passes, the ticket documents the verification and is marked done with
      N/A notes (--force only if genuinely N/A).
