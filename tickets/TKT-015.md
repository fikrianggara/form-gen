## Description

Adding a question to a questionnaire in the dashboard editor does not show
the new question until the page is reloaded; toggling the per-question
"Required" checkbox also does not update until reload.

## Acceptance criteria

- [x] Adding a question renders it immediately in the editor list without a page reload
- [x] Adding a child question renders under its repeatable parent without a reload
- [x] Toggling "Required" on a top-level question updates the checkbox immediately
- [x] Toggling "Required" on a child question updates the checkbox immediately
- [x] Server still persists correctly (question added / required flag saved)
- [x] Regression: existing editor + questionnaire service tests stay green

### Verification (audit 2026-08-14)

- [x] `addQuestion` service returns the created question with `questionMaster` + `optionSet` relations (`include` in `src/services/questionnaire.service.ts`).
- [x] `addQuestionAction` returns `{ question }` to the client (`src/lib/actions/dashboard.ts`).
- [x] Editor appends the returned question to local `items` state (top-level or into the repeatable parent's children) via `toEditorQuestion` (`src/components/dashboard/Editor.tsx`).
- [x] Top-level and child `onToggleRequired` patch `items` optimistically before persisting.
- [x] Integration test "returns the created question with master relations so the editor can render it without a reload (TKT-015)" green; full suite 298 tests on ticket DB; tsc/lint/build clean.
