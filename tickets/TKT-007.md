## Description

"Blok pertanyaan di laman questionnaire, pertanyaan dikelompokan ke 1 blok,
bisa nambahin rule untuk masuk ke blok, rule-nya multi sama kaya pertanyaan":
introduce question BLOCKS — questions are grouped into blocks; a block has its
own entry rule set (same multi-rule semantics as TKT-006); a block shows only
when its rules pass.

## Acceptance criteria

- [x] QuestionnaireBlock model (order, title, entry rules)
- [x] Questions belong to a block (nullable = ungrouped legacy)
- [x] Block entry rules evaluated with the shared multi-rule engine (TKT-006)
- [x] Builder: create/reorder/delete blocks, move questions between them
- [x] Public form renders block grouping + conditional blocks
- [x] Unit + integration tests green

### Verification (audit 2026-08-14)

- [x] `QuestionnaireBlock` model (order, title, multi-set `entryRule`) + `blockId` on questions; migration `20260813130000_question_blocks`.
- [x] Nullable `blockId`; legacy questions render ungrouped (config `blocks` empty).
