## Description

"Blok pertanyaan di laman questionnaire, pertanyaan dikelompokan ke 1 blok,
bisa nambahin rule untuk masuk ke blok, rule-nya multi sama kaya pertanyaan":
introduce question BLOCKS — questions are grouped into blocks; a block has its
own entry rule set (same multi-rule semantics as TKT-006); a block shows only
when its rules pass.

## Acceptance criteria

- [ ] QuestionnaireBlock model (order, title, entry rules)
- [ ] Questions belong to a block (nullable = ungrouped legacy)
- [ ] Block entry rules evaluated with the shared multi-rule engine (TKT-006)
- [ ] Builder: create/reorder/delete blocks, move questions between them
- [ ] Public form renders block grouping + conditional blocks
- [ ] Unit + integration tests green
