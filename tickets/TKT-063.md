## Description

Users can edit a question's content manually inside the questionnaire
editor — title, type, options, required — without going through AI. The
editor today supports question settings (required, option set, block,
repeatable, visibility rule via `updateQuestionSettingsAction`) and master
versioning (`updateQuestionMasterVersionAction`), but inline editing of the
question's own text/type/options is not confirmed end-to-end. First verify
what exists, then build the missing manual-edit surface.

Owner request (2026-08-21): "user bisa edit pertanyaan secara manual."

## Acceptance criteria

- [ ] VERIFY first: grep the editor + question actions for inline editing of
      question title/type/options (e.g. `updateQuestionSettingsAction`,
      `updateQuestionMasterVersionAction`); document what is already
      editable in the ticket before writing code.
- [ ] Editor exposes an explicit "Edit" affordance per question opening an
      inline form: title, type, required, options (if type needs them) —
      labeled controls, not hidden affordances.
- [ ] Saving either updates the question-local settings OR creates a new
      QuestionMaster version and repoints the QuestionnaireQuestion —
      whichever the verification shows fits; no orphan masters.
- [ ] Changes reflect in the editor immediately (R1 convention, analysis v06)
      and in the respondent form (`FormRenderer`).
- [ ] Integration test: manual edit persists, respondent view shows the new
      content.
