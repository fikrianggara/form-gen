## Description

Dashboard currently offers View / Responses / Duplicate / Report / Edit for each
questionnaire — no way to remove one. Add a Delete action with a strict
ownership gate: only an ADMIN or the OPERATOR who created the questionnaire may
delete it (stricter than the generic manage gate, which also allows operators to
manage legacy/org-scoped questionnaires). Deleting a questionnaire removes its
responses (DB cascade already wired: Response.questionnaire onDelete: Cascade)
but must NOT touch question masters or option sets — those are shared bank data
referenced by other questionnaires, not owned by this one.

## Acceptance criteria

- [ ] Delete questionnaire action exists with permission gate: ADMIN always;
      OPERATOR only when questionnaire.createdBy === session.sub
- [ ] Deleting a questionnaire also deletes all its responses (answers,
      answer groups, audits cascade via Response)
- [ ] Question masters and option sets referenced by the deleted questionnaire
      are NOT deleted (shared bank data survives)
- [ ] Confirmation before delete in the dashboard UI (destructive, irreversible)
- [ ] Dashboard reflects deletion (revalidate + redirect on success)
- [ ] Unit + integration tests green
