## Description

"Di questions master dan option set, field pertanyaan yang ngga sesuai tipenya
contoh yang dipilih radio button, maka field panjang karakter didisabled.
Kalau yang dipilih static, maka field external api didisabled": disable
irrelevant form fields based on the selected type/source. E.g. RADIO/CHECKBOX/
SELECT → disable maxLength/placeholder-ish fields; STATIC source → disable
external API fields (URL, method, headers, items path).

## Acceptance criteria

- [ ] Masters form: type-dependent fields disabled per question type
- [ ] Option set form: STATIC disables external API fields, EXTERNAL_API disables static options
- [ ] No behavioral change server-side (UI-only)
- [ ] Tests green
