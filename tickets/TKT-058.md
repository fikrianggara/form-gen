## Description

The current top-navbar-only navigation is confusing (owner's words). Replace
it with a sidebar-based app shell that unifies the separate dashboard
(`src/app/dashboard/layout.tsx`) and admin (`src/app/admin/layout.tsx`)
navbars into one layout with grouped links, plus primary action buttons.
This is the owner's top priority.

Owner request (2026-08-21): "prioritas utama refactor navbar, tambah sidebar
jika diperlukan karena aga bingung navbar yang sekarang. … api key bikin
sidebar yang ngarah ke halaman proposal, kuesioner, organisasi, master
pertanyaan, master options set (digrouping aja jadi tab 'master'). … ada
tombol tambah proposal/survei, kuesioner."

## Acceptance criteria

- [ ] One app shell replaces the two navbar layouts; sidebar groups:
      Dashboard | Proposals | Surveys | Questionnaires | Organizations |
      Master (group: Question masters + Option sets) | API Keys.
- [ ] Sidebar items are permission-aware: ADMIN sees all; OPERATOR sees
      Dashboard, Proposals, Questionnaires (+ Surveys of their org);
      DEV additionally sees API Keys (ISSUE_API_KEYS) and Master-create.
      Admin-only links (Users, manage master data, approve key requests)
      never render for non-ADMIN.
- [ ] Top bar shows username + role badge + theme toggle (TKT-060) + sign out.
      Once TKT-069 lands, the top bar also shows the user's remaining AI
      credit balance (clickable to the generate page).
- [ ] "New" primary actions are reachable from the shell: New Proposal,
      New Survey, New Questionnaire (each links to the existing form pages).
- [ ] A Surveys list page exists for the sidebar link (add `/surveys` or
      route through `/admin/orgs` detail if a standalone list is missing —
      verify first).
- [ ] Sidebar collapses to a hamburger/toggle on narrow screens; active
      route is highlighted; the "confusing navbar" links are gone.
- [ ] No route or permission regression: every existing page reachable as
      before; DEV login lands on the same dashboard (see TKT-065).
- [ ] Component test for the nav model: which links render per role.
