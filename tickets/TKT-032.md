## Description

Data model for the public REST web service (analysis v03 §5): `ApiKey`
(hashed secrets + scopes + lifecycle), `ApiKeyRequest` (self-serve portal
request/approval), `ApiRequestLog` (append-only request metadata). Covers the
migration and Prisma client regeneration.

## Acceptance criteria

- [x] `ApiKey` model: id, name, keyHash (unique, SHA-256), keyPrefix, scopes (Json string[]), status enum (ACTIVE|REVOKED|EXPIRED), expiresAt?, lastUsedAt?, createdBy?, createdAt/updatedAt
- [x] `ApiKeyRequest` model: requesterName, requesterEmail, organization?, purpose, requestedScopes (Json), status enum (PENDING|APPROVED|DENIED), approvedKeyId?, reviewedBy?, reviewedAt?, createdAt/updatedAt
- [x] `ApiRequestLog` model: apiKeyId? (nullable), method, path, statusCode, durationMs, ip?, userAgent?, createdAt; indexes on [apiKeyId, createdAt] and [createdAt]
- [x] Migration generated via `migrate diff` + applied with `migrate deploy` (non-interactive); `npx prisma generate` succeeds
- [x] `npx tsc --noEmit` passes with the new models
- [x] Enum values and Json fields match the analysis v03 §5 spec
