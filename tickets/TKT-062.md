## Description

Beyond whole-questionnaire AI generation (`/dashboard/generate`,
`rag.service:generateQuestionnaireFromPrompt`), let the editor add questions
with AI and edit questions with AI: describe the question (or the change) in
plain language and the RAG/LLM pipeline produces/updates it.

Owner request (2026-08-21): "di pembuatan kuesioner, selain generate
kuesioner dengan AI, user bisa nambah pertanyaan menggunakan AI dan edit
pertanyaan menggunakan AI. tinggal deskripsiin aja pertanyaannya, kaya fitur
generate kuesioner."

## Acceptance criteria

- [ ] "Add with AI" affordance in the questionnaire editor (`Editor.tsx`):
      prompt box → one or more questions generated (title, type, options
      where applicable) → preview → confirm adds them as QuestionnaireQuestion
      rows (new QuestionMaster versions as needed, aiSuggested=true).
- [ ] **Credit cost (TKT-069):** confirming an AI add deducts **2** credits
      via `credit.service`; an AI edit deducts **1**; insufficient credits
      block the action with the typed exhausted error; failed generation
      refunds the deduction.
- [ ] "Edit with AI" affordance per existing question: describe the change →
      LLM proposes an updated master/version → preview diff → confirm applies.
- [ ] Both flows reuse the RAG service and its confidence/novelty flags
      (TKT-008 patterns) and mark low-confidence output for review.
- [ ] User can discard the AI proposal without side effects.
- [ ] Rate-limited / loading states; errors surface via toast; no silent
      partial writes (transaction per add/edit).
- [ ] Integration test: add-with-AI creates masters + questions (mocked LLM);
      edit-with-AI updates the version; discard leaves no rows.
