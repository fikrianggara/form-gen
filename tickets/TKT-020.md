## Description

Invitation tokens (TKT-001) never expire, are never single-use, and cannot be
revoked. The invitation email claims "This link is personal to you and can be
used once" — but `markInvitationClicked` only stamps `clickedAt`, and nothing
rejects a second click. For `acceptMultipleResponses=true` questionnaires one
leaked/forwarded token yields unlimited responses. From finding F-003.

## Acceptance criteria

- [ ] Invitation tokens expire after a configured duration (e.g. N days from
      creation); expired tokens rejected with a clear error
- [ ] Single-use enforcement: once a response is linked to an invitation (or
      the questionnaire is completed), the token no longer opens the form
- [ ] Admin/operator can revoke an invitation (invalidates the token, visible
      in the responses/links UI)
- [ ] Existing invitations keep working during rollout (no mass invalidation)
- [ ] Tests cover expiry, reuse, revoke, and the happy path
